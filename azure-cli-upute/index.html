Slanje cenovnika preko konzole (Azure CLI)

Ovo uputstvo pokazuje kako poslati CSV cenovnike na Azure Blob Storage pomoću Azure CLI-ja, iz konzole. Pogodno je kada šaljete više fajlova odjednom ili želite prenos da automatizujete.

Instalacija se razlikuje po operativnom sistemu; sve ostalo je isto na Windowsu, macOS-u i Linuxu.

Pre početka

Potrebno je:

1. Azure nalog sa pristupom storage nalogu. 2. CSV fajlovi u jednom folderu na računaru.

Podaci za ovaj projekat:

  • Storage Account: ideacenovnici
  • Blob Container: cenovnici

Storage Account i Blob Container nisu ista stvar. Storage Account je Azure resurs koji sadrži kontejnere. U --account-name ide naziv storage naloga, a u --destination naziv kontejnera.

Nemate Azure nalog ili ne želite prijavu u dva koraka? Tražite od nas SAS link i pratite poglavlje Slanje bez Azure naloga (SAS link) niže u ovom uputstvu — tada preskačete korake 2 i 3 u potpunosti.

Korak 1 — Instalacija Azure CLI-ja

Windows

Preuzmite instaler sa https://learn.microsoft.com/cli/azure/install-azure-cli-windows.

Nakon instalacije zatvorite i ponovo otvorite PowerShell.

macOS

Sa Homebrewom:

brew update
brew install azure-cli

Ako nemate Homebrew, instalirajte ga sa https://brew.sh/ pa ponovite komandu.

Linux (Ubuntu / Debian)

curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash

Ako curl nije instaliran:

sudo apt update
sudo apt install curl -y

Provera instalacije

Na svim sistemima:

az --version

Ako dobijete verziju, instalacija je uspela.

Korak 2 — Prijava

az login

Otvara se browser. Prijavite se svojim Azure/Microsoft nalogom.

Ako koristite SAS link, preskočite ovaj korak.

Korak 3 — Provera pretplate

az account list --output table

Ako je potrebno izabrati određenu pretplatu:

az account set --subscription "<NAZIV_ILI_ID_PRETPLATE>"

Ako koristite SAS link, preskočite ovaj korak.

Korak 4 — Slanje CSV fajlova

Komanda šalje sve .csv fajlove iz jednog foldera.

Windows (PowerShell)

Za fajlove u C:\Users\<KORISNIK>\csv:

az storage blob upload-batch `
  --account-name ideacenovnici `
  --destination cenovnici `
  --source "C:\Users\<KORISNIK>\csv" `
  --pattern "*.csv" `
  --auth-mode login

Isto, u jednom redu:

az storage blob upload-batch --account-name ideacenovnici --destination cenovnici --source "C:\Users\<KORISNIK>\csv" --pattern "*.csv" --auth-mode login

macOS i Linux

Za fajlove u ~/csv:

az storage blob upload-batch \
  --account-name ideacenovnici \
  --destination cenovnici \
  --source ~/csv \
  --pattern "*.csv" \
  --auth-mode login

Korak 5 — Provera

Na svim sistemima:

az storage blob list \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --auth-mode login \
  --output table

Rezultat izgleda ovako:

Slanje bez Azure naloga (SAS link)

Ako nemate Azure nalog ili ne želite da se prijavljujete u dva koraka, možemo vam izdati SAS link. To je duga adresa koja sa sobom nosi sopstveno pravo upisa u kontejner:

https://ideacenovnici.blob.core.windows.net/cenovnici?sp=racwl&st=2026-09-01T00:00:00Z&se=2026-12-31T23:59:00Z&sig=...

Uz njega preskačete korake 2 i 3 — nema az login, nema Microsoft naloga, nema koda u drugom koraku. Korak 1 i samo slanje ostaju isti.

Prema linku se ponašajte kao prema lozinki. Ko god ga ima, ima ista prava nad kontejnerom kao i vi, pa ga nemojte prosleđivati ni objavljivati. Ako mislite da je procureo, javite nam i izdaćemo novi, a stari ugasiti. Link ima i ugrađen datum isteka; kada prođe, komande prestaju da rade i treba vam novi link.

Šta se kopira iz linka

Deo iza znaka ? je SAS token. Njega komande traže:

sp=racwl&st=2026-09-01T00:00:00Z&se=2026-12-31T23:59:00Z&sig=...

Kopirajte ga u celosti, uključujući sve iza svakog znaka &. Skraćen token prijavljuje grešku o autentikaciji, a ne poruku da je nepotpun.

Windows (PowerShell)

Token jednom upišite u AZURE_STORAGE_SAS_TOKEN, pa pokrenite uobičajene komande bez dodatnog parametra:

$env:AZURE_STORAGE_SAS_TOKEN = "sp=racwl&st=...&se=...&sig=..."
az storage blob upload-batch `
  --account-name ideacenovnici `
  --destination cenovnici `
  --source "C:\Users\<KORISNIK>\csv" `
  --pattern "*.csv"

Provera na isti način, i dalje bez parametra:

az storage blob list --account-name ideacenovnici --container-name cenovnici --output table

Na Windowsu token nemojte stavljati u --sas-token. Na Windowsu je az skripta, PowerShell uklanja navodnike oko vrednosti bez razmaka, pa se komanda prekida na svakom znaku &. Slanje tada prijavi NoAuthenticationInformation, a zatim greške tipa 'sp' is not recognized as an internal or external command. Promenljiva okruženja zaobilazi problem jer token nikada nije deo komandne linije.

Podešavanje važi dok ne zatvorite prozor. Za trajno, upišite isti red u svoj PowerShell profil — otvorite ga sa notepad $PROFILE.

macOS i Linux

Ovde parametar radi normalno:

az storage blob upload-batch \
  --account-name ideacenovnici \
  --destination cenovnici \
  --source ~/csv \
  --pattern "*.csv" \
  --sas-token "sp=racwl&st=...&se=...&sig=..."
az storage blob list \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --sas-token "sp=racwl&st=...&se=...&sig=..." \
  --output table

Zadržite navodnike — bez njih ljuska preseca token na prvom znaku &.

Ako cenovnike šaljete redovno, promenljiva okruženja i ovde znači manje kucanja:

export AZURE_STORAGE_SAS_TOKEN="sp=racwl&st=...&se=...&sig=..."
az storage blob upload-batch --account-name ideacenovnici --destination cenovnici --source ~/csv --pattern "*.csv"

Red sa export dodajte u ~/.bashrc da ostane trajno.

Jedno ili drugo

I --sas-token i AZURE_STORAGE_SAS_TOKEN zamenjuju --auth-mode login. SAS nikada ne kombinujte sa --auth-mode login u istoj komandi.

Ako nešto ne radi

az nije prepoznata komanda Zatvorite i ponovo otvorite konzolu. Ako i dalje ne radi, instalacija nije završena ili az nije u PATH-u.

Prijava ne uspeva Proverite da se prijavljujete nalogom koji smo vam otvorili, a ne privatnim.

Greška o dozvolama pri slanju Uz --auth-mode login potrebna je rola Storage Blob Data Contributor na kontejneru. Javite se administratoru za dodelu prava.

Nijedan fajl nije poslat Proverite da putanja u --source postoji i da u njoj zaista ima .csv fajlova.

AuthenticationFailed ili 403 uz SAS link Link je istekao ili je kopiran samo delimično. Ponovo kopirajte sve iza znaka ?. Ako i dalje ne radi, tražite novi link.

Na Windowsu: NoAuthenticationInformation, pa 'sp' is not recognized Token je prosleđen preko --sas-token. Na Windowsu ga stavite u AZURE_STORAGE_SAS_TOKEN — vidite poglavlje iznad.

Spisak fajlova radi, ali slanje je odbijeno Link je izdat bez prava upisa. Javite nam i izdaćemo novi.

Zajedno korišćeni --auth-mode login i --sas-token Koristi se jedno ili drugo, nikada oboje u istoj komandi.

Ako zapnete, pošaljite nam tekst greške iz konzole.
