Objavljivanje državnog cenovnika na stalnu adresu

Ovo uputstvo pokazuje kako objaviti jedan cenovnik na adresu koja se nikada ne menja, u folder drzavni unutar kontejnera cenovnici.

Razlika u odnosu na uobičajeno slanje: obični cenovnici se šalju sa datumom u nazivu i svaki je novi fajl. Ovde postoji samo jedan fajl, uvek istog naziva, koji se prepisuje. Zato adresa ostaje ista i sistemi koji je koriste ne moraju ništa da menjaju kada objavite novu verziju.

Stalna adresa

https://ideacenovnici.blob.core.windows.net/cenovnici/drzavni/cene_proizvoda_ideamarketi.csv

Ova adresa radi odmah nakon što fajl postoji. Svako ko je ima može preuzeti fajl, bez prijave.

Pre početka

Potrebno je:

1. Azure nalog sa pravom pisanja u kontejner (rola Storage Blob Data Contributor). 2. CSV fajl koji objavljujete — ili na računaru, ili već poslat u kontejner.

Podaci za ovaj projekat:

  • Storage Account: ideacenovnici
  • Blob Container: cenovnici
  • Folder: drzavni
  • Naziv fajla: cene_proizvoda_ideamarketi.csv

Naziv fajla i foldera pišite tačno ovako, malim slovima. Azure razlikuje velika i mala slova — Cene_Proizvoda.csv nije isti fajl kao cene_proizvoda.csv, i adresa neće raditi.

Varijanta A — kopiranje unutar Azure-a (preporučeno)

Koristite ovo kada je fajl već poslat u kontejner cenovnici. Kopiranje se odvija unutar Azure-a, fajl se ne preuzima na vaš računar i ne šalje ponovo. Kod velikih fajlova to je razlika između nekoliko sekundi i pola sata.

Kroz konzolu

az storage blob copy start \
  --account-name ideacenovnici \
  --destination-container cenovnici \
  --destination-blob "drzavni/cene_proizvoda_ideamarketi.csv" \
  --source-container cenovnici \
  --source-blob "cene_proizvoda_ideamarketi_pregled_2026-08-28.csv" \
  --auth-mode login

Na Windowsu (PowerShell) zamenite \ na kraju reda znakom ` ``, ili sve upišite u jednom redu.

U --source-blob ide naziv fajla koji objavljujete. --destination-blob se ne menja nikada — to je adresa koju partneri koriste.

Kroz Azure Portal

1. Otvorite storage nalog ideacenovnici i u levom meniju kliknite Storage browser.

2. Idite na Blob containers → cenovnici. 3. Označite fajl koji objavljujete i kliknite Copy u traci sa alatkama. 4. Uđite u folder drzavni i kliknite Paste. 5. Označite nalepljeni fajl, kliknite Rename i upišite cene_proizvoda_ideamarketi.csv.

Ako folder drzavni još ne postoji: kliknite Add Directory, upišite drzavni i potvrdite. Folder postaje stvaran tek kada u njega stigne prvi fajl — to je normalno i tako Azure radi.

Varijanta B — slanje fajla sa računara

Koristite ovo kada fajl postoji samo na vašem računaru.

Windows (PowerShell)

az storage blob upload `
  --account-name ideacenovnici `
  --container-name cenovnici `
  --name "drzavni/cene_proizvoda_ideamarketi.csv" `
  --file "C:\Users\<KORISNIK>\csv\cenovnik.csv" `
  --overwrite `
  --content-type "text/csv" `
  --content-cache-control "no-cache, max-age=0" `
  --auth-mode login

macOS i Linux

az storage blob upload \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --name "drzavni/cene_proizvoda_ideamarketi.csv" \
  --file ~/csv/cenovnik.csv \
  --overwrite \
  --content-type "text/csv" \
  --content-cache-control "no-cache, max-age=0" \
  --auth-mode login

Obratite pažnju na dve stvari koje se razlikuju od uobičajenog slanja:

  • Kontejner se ovde navodi kao --container-name, a ne --destination. Kod upload-batch je obrnuto. Ovo je najčešća greška.
  • --name je naziv na Azure-u, zajedno sa folderom. Naziv fajla na vašem računaru nije bitan.

Kroz Azure Portal

Storage browser → cenovnici → drzavni → Upload, izaberite fajl i obavezno označite Overwrite if files already exist. Bez toga slanje neće uspeti jer fajl već postoji.

Ako se naziv fajla na računaru razlikuje, posle slanja upotrebite Rename.

Cache-Control — nemojte preskočiti

Pošto se fajl uvek zove isto, browseri i posrednički serveri ga rado zapamte i danima serviraju staru verziju, iako ste vi objavili novu.

Zato se uz fajl postavlja Cache-Control: no-cache, max-age=0. U komandama iznad to je već uključeno. Kod varijante A kopija nasleđuje osobine originala, pa zaglavlje postavite naknadno:

az storage blob update \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --name "drzavni/cene_proizvoda_ideamarketi.csv" \
  --content-type "text/csv" \
  --content-cache-control "no-cache, max-age=0" \
  --auth-mode login

Kroz Portal: kliknite na fajl → Properties → polje Cache-Control → upišite no-cache, max-age=0 → Save.

Provera

Osnovni podaci o fajlu:

az storage blob show \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --name "drzavni/cene_proizvoda_ideamarketi.csv" \
  --auth-mode login \
  --query "{naziv:name, velicina:properties.contentLength, izmenjen:properties.lastModified, cache:properties.contentSettings.cacheControl}" \
  --output table

Sadržaj foldera:

az storage blob list \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --prefix "drzavni/" \
  --auth-mode login \
  --output table

Provera same adrese, bez preuzimanja fajla:

curl -I https://ideacenovnici.blob.core.windows.net/cenovnici/drzavni/cene_proizvoda_ideamarketi.csv

Očekuje se HTTP/1.1 200 OK, Content-Type: text/csv i Cache-Control koji ste postavili. Koristite -I (velika slova i), ne -i — inače se preuzima ceo fajl, a on može biti veoma velik.

Datum u polju Last-Modified je najbrža provera da je objavljena nova verzija.

Ako nešto ne radi

Adresa vraća BlobNotFound Fajl ne postoji na toj putanji. Najčešće je u pitanju greška u nazivu ili velika slova. Proverite komandom az storage blob list iz odeljka Provera.

Slanje ne uspeva jer fajl već postoji Nedostaje --overwrite, odnosno u Portalu polje Overwrite if files already exist.

Greška o dozvolama Uz --auth-mode login potrebna je rola Storage Blob Data Contributor. Javite se administratoru.

Fajl je poslat, ali se preuzima stara verzija Zaglavlje Cache-Control nije postavljeno. Vidite odeljak iznad. Proverite prvo komandom curl -I — ako curl vraća novi Last-Modified, a browser staru verziju, radi se o kešu u browseru.
