Slanje državnog cenovnika preko konzole (Azure CLI)

Državni cenovnik se šalje u folder drzavni unutar kontejnera cenovnici, uvek pod istim nazivom: cene_proizvoda_ideamarketi.csv. Svako novo slanje prepisuje prethodni fajl, pa adresa ostaje ista.

Za slanje kroz browser vidite Slanje državnog cenovnika preko Azure Portala (DRZAVNI-UPUTSTVO-SR.md).

Adresa na kojoj je cenovnik dostupan

https://ideacenovnici.blob.core.windows.net/cenovnici/drzavni/cene_proizvoda_ideamarketi.csv

Pre početka

Instalacija Azure CLI-ja, prijava (az login) i izbor pretplate identični su kao kod običnog slanja cenovnika. Ako to još niste uradili, uradite korake 1, 2 i 3 iz uputstva Slanje cenovnika preko konzole (Azure CLI) (CLI-UPUTSTVO-SR.md), pa se vratite ovde.

Ako umesto Azure naloga koristite SAS link, uradite samo korak 1 (instalaciju CLI-ja) — koraci 2 i 3 tada ne važe. Zatim koristite komande iz poglavlja Slanje bez Azure naloga (SAS link) niže.

Podaci za ovaj projekat:

  • Storage Account: ideacenovnici
  • Blob Container: cenovnici
  • Putanja: drzavni/cene_proizvoda_ideamarketi.csv

Slanje

Windows (PowerShell)

az storage blob upload `
  --account-name ideacenovnici `
  --container-name cenovnici `
  --name "drzavni/cene_proizvoda_ideamarketi.csv" `
  --file "C:\putanja\do\cenovnik.csv" `
  --overwrite `
  --content-type "text/csv" `
  --content-cache-control "no-cache, max-age=0" `
  --auth-mode login

macOS i Linux

az storage blob upload \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --name "drzavni/cene_proizvoda_ideamarketi.csv" \
  --file ~/cenovnik.csv \
  --overwrite \
  --content-type "text/csv" \
  --content-cache-control "no-cache, max-age=0" \
  --auth-mode login

Komanda je jedna i radi sve odjednom: šalje fajl, prepisuje postojeći i postavlja zaglavlja. Kroz Portal se zaglavlje Cache-Control postavlja odvojeno i gubi se pri svakom novom slanju — ovde ne.

Slanje bez Azure naloga (SAS link)

Ako nemate Azure nalog ili ne želite da se prijavljujete u dva koraka, tražite od nas SAS link. To je duga adresa koja sa sobom nosi sopstveno pravo upisa u kontejner i u potpunosti zamenjuje prijavu.

Deo iza znaka ? je SAS token — on ide u komandu. Držite ga pod navodnicima jer sadrži znak &, koji bi konzola inače shvatila kao razdvajanje komandi. Link ima ugrađen datum isteka i prema njemu se ponašajte kao prema lozinki.

Windows (PowerShell)

az storage blob upload `
  --account-name ideacenovnici `
  --container-name cenovnici `
  --name "drzavni/cene_proizvoda_ideamarketi.csv" `
  --file "C:\putanja\do\cenovnik.csv" `
  --overwrite `
  --content-type "text/csv" `
  --content-cache-control "no-cache, max-age=0" `
  --sas-token "sp=racwl&st=...&se=...&sig=..."

macOS i Linux

az storage blob upload \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --name "drzavni/cene_proizvoda_ideamarketi.csv" \
  --file ~/cenovnik.csv \
  --overwrite \
  --content-type "text/csv" \
  --content-cache-control "no-cache, max-age=0" \
  --sas-token "sp=racwl&st=...&se=...&sig=..."

--sas-token zamenjuje --auth-mode login. Nemojte koristiti oba u istoj komandi.

Pošto se ovaj fajl svaki put prepisuje, SAS link mora imati pravo upisa preko postojećeg fajla. Ako spisak radi, a slanje je odbijeno, link je izdat bez tog prava — javite nam i izdaćemo novi.

Ako cenovnik šaljete često, postavite token jednom umesto da ga lepite u svaku komandu — vidite Ako ovo radite redovno u CLI-UPUTSTVO-SR.md.

Provera

az storage blob list \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --prefix "drzavni/" \
  --auth-mode login \
  --output table

Uz SAS link zamenite poslednji parametar:

az storage blob list \
  --account-name ideacenovnici \
  --container-name cenovnici \
  --prefix "drzavni/" \
  --sas-token "sp=racwl&st=...&se=...&sig=..." \
  --output table

Provera same adrese, bez preuzimanja fajla.

macOS i Linux:

curl -I https://ideacenovnici.blob.core.windows.net/cenovnici/drzavni/cene_proizvoda_ideamarketi.csv

Windows (PowerShell):

curl.exe -I https://ideacenovnici.blob.core.windows.net/cenovnici/drzavni/cene_proizvoda_ideamarketi.csv

U PowerShellu je curl druga komanda, pa pišite curl.exe u punom obliku — inače dobijete grešku oko -I.

Očekuje se HTTP/1.1 200 OK i svež Last-Modified. Koristite -I (veliko i), ne -i — inače se preuzima ceo fajl. Za ovu proveru ne treba ni prijava ni SAS link.

Ako nešto ne radi

BlobAlreadyExists ili slanje ne uspeva Nedostaje --overwrite.

Greška o dozvolama Uz --auth-mode login potrebna je rola Storage Blob Data Contributor. Javite se administratoru.

AuthenticationFailed ili 403 uz SAS link Link je istekao ili je kopiran samo delimično. Ponovo kopirajte sve iza znaka ? ili tražite novi link.

az nije prepoznata komanda Zatvorite i ponovo otvorite konzolu. Ako i dalje ne radi, Azure CLI nije instaliran — vidite korak 1 u uputstvu Slanje cenovnika preko konzole (Azure CLI).

Adresa vraća BlobNotFound Proverite --name — mora biti drzavni/cene_proizvoda_ideamarketi.csv, malim slovima.

Ako zapnete, pošaljite nam tekst greške iz konzole.
